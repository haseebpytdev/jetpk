# One API (FlyJinnah / Air Arabia)

Hybrid supplier integration: REST authentication and search, SOAP price/ancillaries/book/read/modify.

- Internal supplier key: `one_api`
- Customer-facing airline branding from `airlines` table (G9 / Fly Jinnah)
- SOAP URL is **mandatory** on the connection and must be supplied by the vendor (not in public docs)
